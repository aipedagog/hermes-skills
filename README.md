# Навыки для Hermes Agent

Готовые навыки для вашего агента Hermes. Каждый ставится одной командой, отработан автором на своём сервере и приходит без чужих личных данных: под себя вы настраиваете его при первом запуске.

Автор: Алёна Быковская, канал [«Не нанимай»](https://t.me/ne_nanimai): как отдать ИИ работу, ради которой обычно нанимают человека.

## Что внутри

| Навык | Что делает | Что нужно |
|---|---|---|
| [`karusel-chatgpt`](skills/karusel-chatgpt/) | Карусель из 7-8 слайдов для Instagram и Telegram: текст, отрисовка каждого слайда вместе с русскими буквами, сверка букв скриптом, лист на приёмку | Подписка ChatGPT как источник картинок, `ffmpeg`, `python3` |

## Установка

Один навык, в терминале сервера:

```
hermes skills install aipedagog/hermes-skills/skills/karusel-chatgpt
```

Команда спросит подтверждение; с ключом `--yes` в конце ставит без вопроса. По документации Hermes то же самое пишется агенту в чат: `/skills install aipedagog/hermes-skills/skills/karusel-chatgpt`.

Подключить весь репозиторий как источник, чтобы новые навыки появлялись в поиске:

```
hermes skills tap add aipedagog/hermes-skills
```

Перед установкой Hermes проверяет каждый навык сканером безопасности. Посмотреть навык заранее: `hermes skills inspect aipedagog/hermes-skills/skills/<имя>`. Обновить: `hermes skills update <имя>`.

Подробная инструкция, настройка и разбор типовых поломок лежат в `README.md` внутри папки каждого навыка.

## Правило на любой чужой навык

Навык это инструкция, которую агент выполняет с вашими правами. Прежде чем ставить навык из интернета, в том числе этот, откройте его `SKILL.md` и скрипты и прочитайте, что именно он делает. Здесь всё на виду: текстовые файлы и два коротких скрипта.
