# Образцы: что лежит в этой папке

Папка приходит пустой. Образцы появляются во время настройки (раздел «Настройка» в `SKILL.md`), каждый после вашего «да».

| Файл | Что это | Обязателен |
|---|---|---|
| `obrazec-slayd.png` | ваш принятый слайд: по нему держится стиль всех каруселей | да |
| `personazh.png` | ваш постоянный персонаж на ровном фоне | нет |
| `obrazec-akcent.png` | слайд на акцентном фоне, для вывода или подвоха | нет |
| `avtor/` | два ваших настоящих фото, если хотите быть в кадре | нет |

Чужие слайды сюда не кладите: с образца ChatGPT переносит шапку и персонажа.
Примеры того, как выглядит готовый результат у автора навыка, лежат отдельно в `primery/`.
